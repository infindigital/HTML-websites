# midnotarypro.com — redesign

Static site generated by a small Python build. Every page is written to
`<route>/index.html`, so the live URLs stay the same.

## Build

```bash
python3 _build/build.py          # regenerates every page, sitemap.xml, robots.txt and docs/
```

The build fails if any page contains an em dash or a banned marketing phrase, and exits non-zero
when the SEO audit finds an issue (title/description length, duplicate or missing H1, canonical,
breadcrumbs, hreflang, broken internal links).

Content lives in `_build/` (verbatim from `midnotarypro-website-content.pdf`):

| File | Holds |
|------|-------|
| `lib.py` | contact details, social links, header / footer / page shell |
| `components.py` | shared sections (services, reviews, FAQ, country explorer, FBI routes) |
| `countries.py` | Hague and legalization country lists (with audit notes and review date) |
| `facts.py` | Prices and turnaround times, in one place for easy updates |
| `seo_audit.py` | Parses every built page and writes `docs/seo-route-map.md` and `docs/seo-audit.md` |
| `page_home.py` | homepage |
| `pages_inner.py` | all internal pages (EN + ES, jail, FBI, blog) |

The world map (`assets/img/world-map.svg`) is pre-generated. To rebuild it:
`npm i world-atlas` then `python3 _build/make_map.py node_modules/world-atlas`.

## Deploy (Apache / Hostinger)

1. Upload the folder contents to the web root (`_build/`, the PDF and the zip are blocked by `.htaccess`).
2. Contact form: `composer install`, then copy `config.example.php` to `config.php` and fill in the SMTP credentials.
3. Fonts (Google Fonts) and GSAP (cdnjs) load from CDNs at runtime.

## Open items for the client

- Footer links Privacy, Terms, Document handling and Shipping & returns point to `#` until content is supplied.

## Deploy (Vercel)

Import the repo with **Root Directory** `midnotarypro`, Framework **Other**, no build command.
`vercel.json` adds the `/service/` → `/services/` redirect and asset caching; `.vercelignore`
keeps the build sources, PDF, zip and PHP files out of the deployment (same as `.htaccess`).
Vercel can't run PHP, so the contact form only sends email on the Apache/Hostinger host.
