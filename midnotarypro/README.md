# midnotarypro.com — redesign

Static site generated by a small Python build. Every page is written to
`<route>/index.html`, so the live URLs stay the same.

## Build

```bash
python3 _build/build.py          # regenerates every index.html
```

Content lives in `_build/` (verbatim from `midnotarypro-website-content.pdf`):

| File | Holds |
|------|-------|
| `lib.py` | contact details, social links, header / footer / page shell |
| `components.py` | shared sections (services, reviews, FAQ, country explorer, FBI routes) |
| `countries.py` | Hague and legalization country lists |
| `page_home.py` | homepage |
| `pages_inner.py` | all internal pages (EN + ES, jail, FBI, blog) |

The world map (`assets/img/world-map.svg`) is pre-generated. To rebuild it:
`npm i world-atlas` then `python3 _build/make_map.py node_modules/world-atlas`.

## Deploy (Apache / Hostinger)

1. Upload the folder contents to the web root (`_build/`, the PDF and the zip are blocked by `.htaccess`).
2. Contact form: `composer install`, then copy `config.example.php` to `config.php` and fill in the SMTP credentials.
3. Fonts (Google Fonts) and GSAP (cdnjs) load from CDNs at runtime.
