# ARCSHIP India

Country website for ARCSHIP Management & Chartering Private Limited, Navi Mumbai, India.
Static HTML, part of the ARCSHIP international site family (same design system as the
Saudi Arabia, Oman and Sri Lanka sites), localized for India.

## Structure

- `index.html` — homepage (hero, services, India maritime coverage map, offices, FAQ, contact)
- Service pages: `life-saving-appliances.html`, `fire-fighting-appliances.html`,
  `calibration-services.html`, `marine-safety-products.html`, `engine-overhauling.html`,
  `marine-mechanical-solutions.html`, `ship-management.html`
- `about.html`, `approvals-certifications.html`, `gallery.html`, `contact.html`
- `blog/` — blog index + 6 India-focused articles
- `privacy-policy.html`, `terms-of-service.html`, `404.html`
- `css/arcship.css`, `js/arcship.js`, `img/`
- `sitemap.xml`, `robots.txt`
